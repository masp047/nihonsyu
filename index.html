Four Natural Elements

シンプルだからこそ、美しい。
日本酒を形づくる4つの素材

原材料は、驚くほどシンプルで無添加。ベースは「お米と水」という、自然の恵みだけ。そこに二つの微生物が加わって、はじめて日本酒になります。

米

酒造好適米SHUZO-KOTEKIMAI

日本酒のためだけに栽培された大粒の酒米。ご飯用のお米とは異なり、代表格「山田錦」をはじめ、味わいの土台をつくります。

水

仕込み水SHIKOMI-MIZU

日本酒の約80%は水分。山や森が育んだ清冽な天然水を使います。硬水ならキリッと、軟水ならなめらかな口当たりに。

約80%を占める

麹菌KOJI-KIN

お米のデンプンを「糖（甘み）」へ優しく分解する微生物。発酵コスメでもお馴染み、日本の酒造りに欠かせない「国菌」です。

日本の国菌

弐第二章
Parallel Multiple Fermentation

奇跡の発酵コラボレーション。
日本酒ができるまで

酒蔵の中は、職人「杜氏（とうじ）」の緻密な管理のもと、まるで神秘的なバイオテクノロジーの実験室。ひとつのタンクの中で、二つの反応が同時に進みます。

最大の特徴は、1つの仕込みタンクの中で「麹菌がお米を糖に変える糖化」と、「酵母がその糖をアルコールに変える発酵」が同時に進行すること。世界でも類を見ない、極めて高度な発酵システム——それが並行複発酵です。

杜氏は、タンクの品温やアミノ酸などのデータを毎日細かく分析しながら、この微生物たちの共同作業を、我が子を見守るようにコントロール。この丁寧な手仕事こそが、洗練されたクリアな味わいを生み出します。

Saccharification — 糖化（麹の働き）
(C6H10O5)n + nH2O → nC6H12O6 （ブドウ糖）
Alcohol Fermentation — 発酵（酵母の働き）
C6H12O6 → 2C2H5OH + 2CO2

この二つが同じタンクで同時に起こる調和を、科学は「並行複発酵」と呼びます。

肆第四章
The Light-Shielding Bottle

美味しさをキープする、
美しい「遮光ボトル」の秘密

日本酒の瓶は、なぜ茶色や深緑が多い？ 日本酒の大敵は光——特に紫外線。数時間の蛍光灯やLEDでも成分が光分解し、「日光臭」でせっかくの香りが台無しに。色つきの瓶は、いわば日本酒専用のサングラスなのです。

茶色の瓶

紫外線カットほぼ100%

紫外線をほぼ完全に遮断。最も品質保持力に優れた、頼れるプロテクターです。

緑色の瓶

紫外線カット高い

茶色に次ぐ遮光性。和のテーブルにも美しく馴染むデザイン性から人気です。

透明・青の瓶

紫外線カット低い

光を通しやすいぶん、冷蔵で厳重管理する「生酒」や、涼しげな夏限定酒によく使われます。

冷

おうちでのスマートな保存方法

たとえ茶色の瓶でも、光が当たらず温度変化の少ない冷蔵庫（できれば野菜室）へ。新聞紙やおしゃれな包装紙で瓶ごと包んで光を完全に遮れば、開栓時のフレッシュな美味しさが驚くほど長持ちします。

伍第五章
Reading the Back Label

「ジャケ買い」から始める、
裏ラベルのスマートな読み解き方

洗練されたラベルをビジュアルで選ぶ「ジャケ買い」も立派な楽しみ方。さらに裏ラベルの数字を少し読めれば、飲む前のワクワクがぐっと広がります。

裏ラベルBACK LABEL
アルコール度数義務表示ALCOHOL
15%前後
一般的には15度前後。最近は12度前後に抑え、ワインのようにカジュアルに楽しめる「低アルコール日本酒」もトレンドです。
精米歩合義務表示POLISHING RATIO
40%
お米を磨いて残した割合。数字が小さいほど芯のピュアな部分だけを使い、雑味のないクリアで上品な味わいに。
日本酒度任意表示SAKE METER VALUE
−3 / +5
味わいの甘辛の目安。マイナスはお米の自然な甘みを感じやすく、プラスは後味スッキリの辛口に。
酸度任意表示ACIDITY
1.6
乳酸や琥珀酸などの量。高いとコクのあるフルボディ、低いと淡麗で軽やかなライトボディな印象に。
数字は、杜氏からの手紙。 精米歩合で「透明感」を、日本酒度で「甘辛」を、酸度で「ボディ感」を——。たった数行の数字が、そのお酒の設計図であり、造り手のこだわりの表明です。

まずは直感の「ジャケ買い」から。慣れてきたら裏ラベルをそっとめくって、一本の物語を読み解いてみてください。
